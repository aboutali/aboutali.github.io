A web app that aggregates bookable fitness classes from three Zurich studios into one live schedule.

What it is

An aggregated fitness-class schedule pulling from three Zurich studios — Balboa Move, BOOSTD, and Barry's Switzerland — so a class booked across three separate systems shows up in one place instead of three tabs.

How it works

An Express server serves the merged schedule; a separate fetch script pulls each studio on demand via a --studio flag (balboa, boostd, or barrys), or all three at once. Studio booking pages tend to be JS-rendered and defensive about automated traffic, which is why the fetcher runs on Playwright with a stealth plugin rather than a plain HTTP client.
