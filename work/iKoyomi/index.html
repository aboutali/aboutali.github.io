iKoyomi

A minimalist Zen PWA that presents Japan's 72 microseasons as full-screen scenes, each with kanji, a poetic line, and a daily contemplation.

What it is

Japan's 72 microseasons (shichijūni kō), one full-screen scene at a time. Today opens on the current microseason over a full-bleed image with its kanji, reading, literal gloss, a poetic line, and a contemplation prompt. Browse the year turns the same view into a vertical scroll-snap pager through all 72, each panel recoloring the whole UI to that season's palette, with a Today pill to snap back to now.

How it works

An installable, offline-capable PWA: the app shell precaches, and season images cache as you view them. Every one of the 72 seasons falls back gracefully to a palette gradient when its photo hasn't been generated yet, so the app looks finished before all the imagery exists — the 72 images are AI-generated, added a few at a time.

Decisions & trade-offs

The season-turn notification is opt-in, local, and check-on-open by design — no backend, no push infrastructure, no account. That's a deliberate ceiling: a guaranteed daily push would need a server, and it stays on the project's backlog rather than forcing infrastructure onto what is otherwise a fully static app.
