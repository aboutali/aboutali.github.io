life-improver

An interactive framework that maps a full life into seven domains and 300+ practices drawn from psychology, philosophy, and contemplative traditions.

Stack

What it is

Four tabs over one framework. Overview lays out the seven domains — Body, Mind, Work, Relationships, Community, Inner Life, Play — and their 30 subcategories. Self-Assessment has you rate each subcategory 1–10 on a slider and returns a dashboard: overall score, per-domain averages, a tier distribution, and your strongest and weakest areas. Ideas to Improve lists ten curated practices per subcategory. Sources indexes every theory, study, and tradition the practices draw on, organized by discipline — among them Aristotle, the Buddhist canon, Maslow, Frankl, Csikszentmihalyi, and the Harvard Study of Adult Development.

How it works

No backend: the whole app is a static React/Vite build, and a self-assessment persists entirely to the browser's localStorage. The framework itself is data, not code — a single framework.js file holds the domains, subcategories, and practices, so extending it is a pull request against a schema rather than a code change.

Decisions & trade-offs

Two conventions keep that data file safe to extend: each domain's id is load-bearing, since score keys are derived from it, so ids are never reused or renumbered; and subcategory order is append-only, for the same reason — reordering would silently strand a returning visitor's saved scores.
