This site is an index of things I've built and, from now on, an occasional place
to write about building them. The projects cover a wide range, from policy digests
to health-data tools to life-design frameworks. That range is deliberate. I follow
what's interesting, then finish it properly.

## How it's built

Deliberately boring, in the best way. Plain HTML and hand-written stylesheets, no
frameworks, no build step. A single GitHub Action runs daily. It pings each project to light a status
dot, pulls the latest commits into the ticker on the homepage, and renders the
guestbook straight from GitHub issues. The identity is set like an academic paper, in
Newsreader and JetBrains Mono, black on white. It was designed first as a small
design system, then the site was built to follow it.

## What to expect here

Short notes, mostly. Decisions and trade-offs from the projects, occasional
thoughts on policy and technology, and things worth paying attention to. There is
no schedule and no newsletter. A new post shows up here when there's something
worth writing.
